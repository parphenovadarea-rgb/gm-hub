Game Master Hub
===============

Ассистент ведущего настольных ролевых игр: запись на игровые сессии с лимитом
мест, заявки Игроков, сюжетный блокнот Мастера и база знаний мира.

Учебная практика УП.01 «Разработка программных модулей программного
обеспечения для компьютерных систем», группа ИСП-34, Парфенова Д.Г.

Возможности
-----------

Мастер:

* публикует, изменяет, отменяет и удаляет игровые сессии с лимитом мест;
* подтверждает и отклоняет заявки (с причиной отказа), видит лист ожидания;
* ведёт сюжетный блокнот, итоги прошедших игр, бросает кубики d4–d20;
* ведёт базу мира (лор, NPC, локации), смотрит статистику и календарь;
* сохраняет состав сессии в CSV для Excel.

Игрок:

* ведёт карточки персонажей;
* выбирает Мастера и сессию на витрине, подаёт заявку персонажем;
* видит статусы заявок, решения Мастеров и итоги прошедших игр.

Общее: регистрация и вход с ролью, светлая и тёмная темы, крупный текст,
справка по F1, горячие клавиши.

Запуск готовой программы
------------------------

Скачайте архив из раздела Releases, распакуйте его в любую папку и запустите
``GameMasterHub.exe`` (Python не нужен). В архиве лежит демонстрационная база:
пароль у всех пользователей — ``1234``, Мастера ``агыг`` и ``ilin``, Игроки
``gleb``, ``polina``, ``artem``, ``elena``, ``nikita``, ``vera``.

Запуск из исходного кода
------------------------

.. code-block:: text

   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements-dev.txt
   py main.py

Демонстрационная база в отдельном файле: ``py seed.py demo.db``.

Проверка и сборка
-----------------

.. code-block:: text

   py -m unittest discover -s tests                    автотесты
   py -m coverage run -m unittest discover -s tests    покрытие кода
   py -m coverage report
   py -m flake8 gm_hub main.py tests                   стиль кода
   py -m black --check gm_hub main.py tests            форматирование
   build.bat                                           dist\GameMasterHub.exe

158 автотестов (правила, граничные условия, безопасность, окна без экрана),
покрытие кода — 92 %.
