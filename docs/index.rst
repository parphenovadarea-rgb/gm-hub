Game Master Hub — документация
===============================

Аннотация
---------

Документация к автоматизированной системе «Game Master Hub» — настольному
приложению для Ведущих (Мастеров) и Игроков настольных ролевых игр. Программа
заменяет запись на игры в чатах: Мастер публикует игровые сессии с лимитом
мест, Игроки подают заявки персонажами, Мастер подтверждает или отклоняет их,
ведёт сюжетный блокнот и базу знаний мира.

В документации описаны архитектура и функции приложения, программный
интерфейс (автоматически собран из docstrings исходного кода) и четыре
руководства, составленные по ЕСПД (ГОСТ 19.105-78, 19.503-79, 19.505-79 и по
образцу руководства программиста): руководство оператора, руководство
программиста, руководство системного программиста и руководство разработчика.
В конце — порядок отслеживания ошибок и бэклог продукта.

Приложение написано на Python 3.13 с интерфейсом на PySide6 (Qt), данные
хранятся в SQLite. Исходный код: https://github.com/parphenovadarea-rgb/gm-hub
