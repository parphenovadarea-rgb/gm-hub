Инструкция по запуску и настройке
=================================

Инструкция для пользователя, который получил программу «Game Master Hub»
готовым файлом. Рядом с ней лежит краткая версия — файл «Как запустить.txt».

1. Что вы получили
------------------

Архив содержит три файла:

* ``GameMasterHub.exe`` — программа (один файл, Python устанавливать не нужно);
* ``gm_hub.db`` — демонстрационная база с готовыми пользователями и играми;
* ``Как запустить.txt`` — краткая инструкция.

2. Запуск
---------

1. Распакуйте архив в любую папку, где у вас есть право записи (например, в
   «Документы»). Не запускайте программу прямо из архива и не кладите её в
   ``Program Files``: рядом с ней создаются файлы данных.
2. Дважды щёлкните ``GameMasterHub.exe``. Первый запуск занимает около секунды.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер»,
   нажмите «Подробнее» и «Выполнить в любом случае». Так бывает со всеми
   программами без цифровой подписи.
4. Войдите под одним из готовых пользователей (пароль у всех — ``1234``):
   Мастера — ``агыг`` и ``ilin``; Игроки — ``gleb``, ``polina``, ``artem``,
   ``elena``, ``nikita``, ``vera``. Можно и зарегистрироваться самому.

3. Настройка
------------

Программа не требует настройки. Все данные хранятся рядом с ней:

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Файл
     - Что в нём
   * - ``gm_hub.db``
     - все пользователи, сессии, заявки, персонажи и заметки; чтобы перенести
       данные на другой компьютер, скопируйте этот файл
   * - ``settings.json``
     - тема, запомненные логины, последняя вкладка, размер окна; удалите файл,
       чтобы сбросить настройки
   * - ``gm_hub.log``
     - журнал непредвиденных ошибок; появляется только если ошибка была

Начать с чистого листа: закройте программу и удалите ``gm_hub.db`` — при
следующем запуске откроется регистрация первого пользователя.

Внешний вид меняется в самой программе: ссылка «Тёмная тема» в шапке окна и
переключатель «Крупный текст» в «Профиле».

4. Запуск из исходного кода (для разработчика)
----------------------------------------------

Программа запускается только внутри виртуального окружения проекта:

.. code-block:: text

   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   run.bat

Сборка исполняемого файла: ``build.bat`` создаёт один файл
``dist\GameMasterHub.exe``; ``build_folder.bat`` — папку
``dist\GameMasterHub`` (запускается быстрее, но папка ``_internal`` должна
лежать рядом с файлом).

5. Устранение возможных проблем
-------------------------------

.. list-table::
   :header-rows: 1
   :widths: 32 30 38

   * - Что случилось
     - Возможная причина
     - Что сделать
   * - Windows пишет «защитила ваш компьютер»
     - у программы нет цифровой подписи
     - «Подробнее» → «Выполнить в любом случае»
   * - антивирус удалил или заблокировал программу
     - программа неизвестна антивирусу
     - добавьте файл в исключения антивируса и распакуйте архив заново
   * - программа не открывается, окно не появляется
     - запуск прямо из архива или нет права записи в папке
     - распакуйте архив в «Документы» и запустите оттуда
   * - окно открылось слишком маленьким или за краем экрана
     - сохранён размер окна от другого монитора
     - закройте программу и удалите ``settings.json``
   * - «Ошибка базы данных»
     - файл ``gm_hub.db`` открыт во второй копии программы или защищён от записи
     - закройте другие копии программы, проверьте, что файл не «только для чтения»
   * - вместо ваших данных пустая программа
     - программа запущена из другой папки: данные лежат рядом с ``.exe``
     - запускайте программу из той папки, где лежит ваш ``gm_hub.db``
   * - забыт пароль
     - пароль хранится в виде хэша, восстановить его нельзя
     - зарегистрируйте нового пользователя; если пользователь был один — удалите ``gm_hub.db``
   * - «Непредвиденная ошибка»
     - ошибка в программе
     - перезапустите программу; если повторяется, отправьте разработчику файл ``gm_hub.log``
   * - текст слишком мелкий
     - высокое разрешение экрана
     - «Профиль» → «Крупный текст»
   * - ``ModuleNotFoundError: PySide6`` (при запуске из кода)
     - не активировано виртуальное окружение
     - выполните ``.venv\Scripts\activate`` и ``pip install -r requirements.txt``
   * - ``py`` не найден (при запуске из кода)
     - Python не установлен или нет в PATH
     - установите Python 3.13 с отметкой «Add python.exe to PATH»
