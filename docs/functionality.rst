Функциональность приложения
===========================

В программе две роли: **Мастер** (ведёт игры) и **Игрок** (записывается на них).
Роль выбирается при регистрации; кабинет открывается по роли, а чужие данные
недоступны: у каждого Мастера свои сессии, заявки, заметки и база мира.

Кабинет Мастера
---------------

Расписание
~~~~~~~~~~

* таблица сессий с фильтром «Предстоящие / Прошедшие / Отменённые»;
  занятость мест показана полоской, сессии, до которых меньше трёх дней,
  подсвечены;
* форма справа: название, описание для игроков, дата и время (вводятся только
  цифры, точки и двоеточие ставятся сами, дату можно выбрать в календаре) и
  лимит мест;
* дата в прошлом не принимается; лимит нельзя сделать меньше числа уже
  подтверждённых заявок;
* кнопка «Отменить сессию» отклоняет все заявки на рассмотрении с причиной
  «Сессия отменена»; кнопка «Удалить» есть только на вкладке «Отменённые».

Заявки
~~~~~~

* выбор сессии и фильтр по статусу, число свободных мест полоской;
* новая заявка подсвечена, у неё кнопки «Подтвердить» и «Отклонить» (при отказе
  можно указать причину — Игрок её увидит);
* когда мест нет, кнопка «Подтвердить» неактивна, а новые заявки стоят в листе
  ожидания («№1 в очереди»);
* справа — карточка персонажа (раса, класс, уровень, предыстория);
* один Игрок не может занять одну сессию двумя персонажами.

Сюжетный блокнот
~~~~~~~~~~~~~~~~

* заметка к каждой сессии, видна только Мастеру; дата изменения ставится сама;
  поиск по названию и тексту заметок;
* состав подтверждённых персонажей и кнопка «Сохранить список» (файл CSV для
  Excel);
* у прошедшей сессии — поле «Итоги для игроков» и кнопка «Повысить уровень
  участникам (+1)» (один раз за сессию);
* кубики d4, d6, d8, d10, d12 и d20 с выбором числа бросков.

База мира
~~~~~~~~~

Записи трёх категорий («Лор», «NPC», «Локации») с поиском по заголовку,
фильтром и счётчиками по категориям.

Статистика и календарь
~~~~~~~~~~~~~~~~~~~~~~

«Статистика» показывает число предстоящих, проведённых и отменённых сессий,
среднюю заполняемость прошедших и самых активных игроков. «Календарь» —
сетку месяца с сессиями по дням; щелчок по сессии открывает её для изменения.

Кабинет Игрока
--------------

Витрина сессий
~~~~~~~~~~~~~~

Слева — Мастера с поиском по имени, в центре — его предстоящие сессии с
фильтрами «Все даты / 7 дней / 30 дней» и «Только со свободными местами»,
справа — форма записи: выбор персонажа карточкой, комментарий Мастеру и кнопка
«Отправить заявку» (если мест нет — «Встать в очередь»). Над витриной —
напоминание о ближайшей подтверждённой игре (в ближайшие 3 дня).

Мои записи
~~~~~~~~~~

Статусы заявок у всех Мастеров («На рассмотрении», «Подтверждена», «Отклонена»),
причина отказа, место в очереди, отметка «новое» у решений, принятых после
прошлого просмотра, и итоги прошедших игр. Заявку на рассмотрении или
подтверждённую можно отозвать. Двойной щелчок открывает сессию на витрине.

Мои персонажи
~~~~~~~~~~~~~

Карточки персонажей: имя, раса и класс (из справочника по SRD 5.1, можно
ввести свои), уровень, предыстория; в списке показано число заявок персонажа.
Персонажа с активной заявкой удалить нельзя.

Общие возможности
-----------------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - Возможность
     - Описание
   * - Тёмная тема
     - ссылка в шапке окна; выбор запоминается; пользователь остаётся в своём кабинете
   * - Крупный текст
     - переключатель в «Профиле»: шрифты и окно больше на 15 %
   * - Профиль
     - смена ФИО и пароля после ввода текущего пароля, удаление аккаунта
   * - Справка
     - клавиша F1 или ссылка «Справка» в шапке
   * - Горячие клавиши
     - Ctrl+S — сохранить, Ctrl+N — новая запись, Ctrl+F — к поиску, Delete — удалить выбранную строку, Enter в форме сессии — сохранить, Esc — очистить форму
   * - Подсказки логинов
     - окно входа предлагает логины, с которыми уже входили на этом компьютере (пароли не сохраняются)
   * - Защита правок
     - при смене вкладки, выходе и смене темы программа спрашивает, что делать с несохранёнными правками
   * - Запоминание
     - последняя вкладка, размер и положение окна, выбранный Мастер

Примеры сценариев
-----------------

Подтверждение заявки Игрока
~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Мастер публикует сессию «Шахта Эхо, ч. 3» на 5 мест (вкладка «Расписание»).
2. Игрок на витрине выбирает эту сессию, своего персонажа и нажимает
   «Отправить заявку» — заявка получает статус «На рассмотрении».
3. У Мастера на вкладке «Заявки (1)» появляется подсвеченная строка;
   он нажимает «Подтвердить», свободных мест становится на одно меньше
   (F = M − C).
4. Игрок в «Мои записи» видит статус «Подтверждена» с отметкой «новое».

Запись в очередь
~~~~~~~~~~~~~~~~

Если все места заняты, Игрок всё равно может подать заявку — кнопка называется
«Встать в очередь». Такая заявка стоит в листе ожидания; когда место
освободится (Игрок отозвал подтверждённую заявку или Мастер увеличил лимит),
Мастер подтверждает первую в очереди.
