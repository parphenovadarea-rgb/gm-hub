# Game Master Hub

Ассистент ведущего настольных ролевых игр: расписание сессий, запись игроков,
сюжетный блокнот Мастера. Учебная практика УП.01, группа ИСП-34.

**Стек:** Python 3.10+, SQLite (`sqlite3`), Tkinter/ttk, `hashlib`.
Сторонние библиотеки для работы программы не нужны.

## Запуск

```
py seed.py              демо-БД (пароль у всех 1234: master, gleb, artem, elena, polina)
py main.py              запуск программы
py -m unittest -v       тесты по сценариям п. 6.1 ТЗ
```

Без `seed.py` программа создаст пустую БД и при первом запуске откроет регистрацию.

## Структура (три уровня, п. 4.1.1 ТЗ)

```
gm_hub/
  config.py            путь к БД, форматы дат
  db/                  уровень данных
    schema.sql         6 таблиц по приложению А ТЗ
    database.py        подключение, PRAGMA foreign_keys = ON
  logic/               бизнес-логика (без Tkinter)
    errors.py          ошибки с полем и причиной для пользователя
    auth.py            регистрация и вход, SHA-256 с солью, проверка роли
    characters.py      персонажи, запрет удаления при активной заявке
    games.py           сессии, F = M − C
    signups.py         заявки, подтверждение только при C < M
    notes.py           сюжетный блокнот и база мира (только Мастер)
  ui/                  окна по макетам Figma
    common.py          цвета, стили, таблицы с сортировкой
    auth_windows.py    вход и регистрация
    gm_window.py       Мастер: Расписание, Заявки, Сюжетный блокнот, База мира
    player_window.py   Игрок: Витрина сессий, Мои записи, Мои персонажи
    app.py             переключение окон, вывод ошибок без аварийного выхода
tests/                 тесты по сценариям 1–14 п. 6.1 ТЗ
main.py                точка входа
seed.py                демонстрационные данные
```

## Инструменты разработки

```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
pre-commit install
black .
flake8
```

## Ветки

Feature Branch Workflow: `main` содержит только рабочий код, каждая функция
делается в своей ветке и попадает в `main` через Pull Request:
`feature/auth` → `feature/logic` → `feature/ui`.
